# 配置与数据说明

## 1. 文件清单

| 文件 | 作用 |
|---|---|
| `GameConfig.xlsx` | 唯一的策划配置源表（波次、怪物、玩家、经济等全部数值） |
| `items.json` | 由 Excel 导出的物品表（id/名称/图标/堆叠上限/伤害/耐久…） |
| `drops.json` | 掉落表（敌人种类 → 物品与数量区间） |
| `recipes.json` | 制作配方（产出 → 消耗材料） |

## 2. 导入方式

1. 在 Unity 编辑器打开工程；
2. 菜单 **Tools ▸ Ares ▸ Import Excel Config**；
3. 工具读取 `Assets/Config/GameConfig.xlsx`，生成/覆盖 `Assets/Resources/Config/*.json`；
4. 运行时 `ItemDatabase.Init()` 读取这些 JSON，`GameConfig` 直接从 Excel 生成的字段读数值。

## 3. JSON 结构

```json
{ "items": [ { "id": "wep_dao", "name": "砍刀", "icon": "icon_wuqi_dao",
    "stackMax": 1, "category": "武器", "desc": "…", "weaponKind": 1,
    "damage": 24, "attackInterval": 0.36, "range": 1.5, "durabilityMax": 45,
    "ammoItemId": "", "ammoPerShot": 0, "projectileSpeed": 0,
    "projectileLife": 0, "healAmount": 0, "fx": "" } ] }
```
- `weaponKind`：0 材料 / 1 近战 / 2 远程
- `fx`：远程武器弹道样式（`fire` 火枪、`feather` 弓）

## 4. 存档位置

```
%USERPROFILE%\AppData\LocalLow\HotZone\Ares Virus Arena 2\AresSave\ares_save.db
```
SQLite 单文件，内容为：背包与仓库、装备与耐久、改造/强化等级、里程碑、救济与折扣状态、通关奖励。
启动时由 `SaveService` 读取，退出/关键操作时写回；备份该文件即可整体迁移存档。
